## Що тут можна дізнатися

**З ким найбільше спілкуєшся — і які слова повторюєте найчастіше.**

Відкрий JSON-експорт Telegram. «ChatCount» покажуть два окремі топи слів з іменами учасників. Браузерна версія також сортує всі особисті чати за кількістю повідомлень і показує, скільки надіслала кожна сторона.

- **Менше «я», «не», «і».** Фільтри української, англійської та російської працюють одночасно. За замовчуванням — слова від 3 літер.
- **Зручне порівняння.** Два учасники поруч, кількість повторів і власний список винятків.
- **Три мови інтерфейсу.** Українська, English, Русский. Імена та повідомлення не перекладаються.
- **Результати з собою.** Збереження таблиць у CSV для Excel, Numbers або LibreOffice.
- **Локальна обробка.** Без входу в Telegram, серверів, аналітики та надсилання переписки в мережу.

## Перший запуск

1. У Telegram Desktop експортуй потрібний чат або всі особисті чати у форматі **JSON**. Медіафайли можна не завантажувати.
2. У «ChatCount» натисни **Відкрити JSON** і вибери `result.json`.
3. Вибери переписку та учасників. За потреби зміни мінімальну довжину слова або додай свої винятки.

У браузерній версії є кнопка **Відкрити приклад** — можна спробувати без власної переписки. [Докладніше про експорт →](docs/EXPORT.md)

## Як рахуємо

Регістр і різні апострофи прирівнюються. Відмінки та інші форми слів рахуються окремо. Посилання, цифри та емодзі не входять до топу слів. Голосові не розшифровуються; підписи до медіа враховуються.

Рейтинг чатів включає повідомлення обох сторін: текст, голосові, стікери й медіа. Службові події, групи, канали та «Збережене» виключаються. Боти можуть потрапити в список, якщо експорт позначає їх як особистий чат. Розподіл «твої / їхні» потребує повного експорту акаунта.

Аналіз охоплює лише наданий файл. Видалених повідомлень у ньому немає. Якщо експортувати лише частину історії, результат стосуватиметься саме цієї частини.

## Дані та приватність

Експорт читається лише після вибору файлу й залишається в пам’яті застосунку до закриття. CSV записується тільки після натискання кнопки збереження. У репозиторії та архівах є лише код і вигаданий приклад — особистих переписок немає.

## Для розробників

```text
web/ChatCount.html       Автономна браузерна версія
macos/Source/          SwiftUI-застосунок та підрахунок
macos/Tests/           Перевірки нативної версії
tests/                Перевірки JavaScript і вигаданий приклад
docs/                 Інструкції
```

Браузерна версія не потребує збірки. Для її тестів достатньо Node.js 20+:

```sh
node tests/web.test.cjs
```

Для macOS потрібні Apple Command Line Tools:

```sh
cd macos
zsh build.command
```

Нативні перевірки з кореня репозиторію:

```sh
swiftc macos/Source/Analysis.swift macos/Source/Localization.swift macos/Tests/main.swift -o /tmp/chatcount-tests
/tmp/chatcount-tests
```

Автоматичні перевірки охоплюють підрахунок, авторів, форматований текст, фільтри трьох мов, переклади й CSV. Нативний застосунок перевірявся на macOS. Ручне тестування на Windows і Linux ще не проводилося.

Знайшов помилку? [Створи issue](https://github.com/NODEPY/chatcount/issues). Додай кроки відтворення та маленький вигаданий приклад — приватний `result.json` публікувати не потрібно.
