# Changelog

## 1.0.0 — 2026-10-11

First release under the **ChatCount** name.

- Native macOS application and standalone browser editions for Windows and Linux.
- Top ten words per participant, with names and counts.
- Simultaneous Ukrainian, English and Russian common-word filters.
- Three interface languages and adjustable minimum word length.
- Personal-chat ranking in the browser edition.
- CSV exports, fictional sample data and automated analysis tests.
