Відкрийте експорт Telegram

Виберіть result.json. Для рейтингу всіх чатів використайте повний експорт акаунта.

  1. Усі чати: Telegram Desktop → Налаштування → Розширені → Експорт даних Telegram → особисті чати.
  2. Один чат: меню ⋯ у переписці → Експорт історії чату.
  3. Формат: JSON. Фото й відео завантажувати не потрібно.

Фільтри: українська, English, русский

Регістр не враховується. Різні форми слів рахуються окремо. Посилання, цифри й емодзі пропускаються.
