# Як отримати експорт Telegram

Потрібен **Telegram Desktop** з [офіційного сайту](https://desktop.telegram.org/). Експорт у мобільному або вебклієнті може бути недоступний.

## Одна переписка

1. Відкрий чат і меню **⋯**.
2. Вибери **Export chat history / Експорт історії чату**.
3. Вибери **JSON**. Фото, відео та інші медіафайли для підрахунку не потрібні.
4. Заверши експорт. У «ChatCount» відкрий файл `result.json`.

## Рейтинг усіх чатів

1. **Налаштування → Розширені → Експорт даних Telegram**.
2. Увімкни **особисті чати** та вибери **JSON**.
3. Для повної статистики не обмежуй діапазон дат.
4. Відкрий `result.json` у браузерній версії «ChatCount» і перейди до **Рейтингу чатів**.

HTML-експорт Telegram не підтримується. Якщо маєш `messages.html`, повтори експорт у JSON. Сам застосунок `ChatCount.html` — це програма, яка читає JSON, а не файл переписки.

[Офіційна інструкція Telegram](https://bugs.telegram.org/c/60).
